# 手機安裝指南（OPPO / ColorOS）

拿到 APK 後照這三步裝：

## 1. 把 APK 傳到手機
任選一種：
- **USB 線**：插線後在手機選「傳輸檔案」，把 ClassMate.apk 複製到「下載」資料夾
- **微信/QQ**：檔案傳輸助手發送 → 手機上長按 →「用其他應用程式開啟」→ 文件管理
- **網盤**（夸克/百度網盤等）
- **ADB**（開發者）：adb install ClassMate.apk

## 2. 安裝
1. 手機「文件管理」→ 下載 → 點 ClassMate.apk
2. OPPO 會彈「禁止安裝未知來源應用」→ 點「設定」→ 開啟「允許安裝未知應用」→ 返回再點一次安裝
3. 安裝完成 → 打開 App

## 3. 首次授權（每次都要點「允許」）
| 權限 | 用途 |
|---|---|
| 麥克風 | 聽課辨識（**必須**） |
| 通知 | 前台服務＋彈窗提醒 |
| 顯示在其他應用程式上層（懸浮窗） | 課堂中彈窗提示 |
| 後台運行/自啟動/電池不設限制 | 鎖屏後繼續聽（OPPO 必開，見 android/README_OPPO_GUIDE.md 表格） |

## 4. 開始用
1. 設定 → 填你的名字（中文/英文/粵語叫法）→ 儲存（點名提醒用）
2. 選擇科目（如「感染控制」）
3. 按「開始聆聽」，把手機放桌上
4. 老師提問 → 彈窗即時答案；叫你名 → 紅色警示＋簡潔答案
5. 想自訂熱詞 → 「科目」頁 → ＋ 自訂熱詞
