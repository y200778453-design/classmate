## 二、關鍵情境驗證

1. **粵語提問**：「咩係標準預防措施？」→ 偵測為問題（yue）→ 彈窗附熱詞「標準預防措施」筆記，來源 kb。✅
2. **英語提問**：「What is the difference between disinfection and sterilization?」→ en 偵測 → 命中「消毒與滅菌」。✅
3. **普通話提問**：「為什麼多重耐藥菌越來越常見？」→ zh 偵測 → 命中「抗生素耐藥性」（已加入多重耐藥菌別名）。✅
4. **點名**：「李小明，你嚟答下MRSA要點樣隔離？」→ 紅色警示彈窗「⚠ 點名！請回答」＋強制簡潔答案（MRSA 接觸隔離要點）。✅
5. **點名無提問**：「李小明！」→ 自動沿用**最近一條問題**作答。✅
6. **陳述句**：「今日講到呢度」→ 不觸發彈窗（避免誤報）。✅
7. **模式切換**：簡潔↔深入研討即時重新作答（kb / framework），深入模式含定義→機制→臨床→護理結構。✅
8. **靈敏度**：10（溫柔）→「洗手咩？」不觸發；90（敏銳）→ 觸發；錯字「醣尿病」在敏銳檔命中「糖尿病」。✅
9. **自訂熱詞**：加入「濕性敷料」→ 提問命中 → 移除後回復。✅
10. **歷史紀錄**：自動存檔、搜尋、匯出 JSON、清空（SQLite WAL，跨進程持久）。✅

## 五、修復紀錄（自測發現並修復）

1. count_today 縮排損壞 → 修復。
2. 中文無空格導致詞數計數錯誤 → CJK 字元計數模型。
3. 熱詞模糊匹配閾值用錯候選詞 → 每候選詞獨立閾值＋滑窗。
4. PySide6 Signal 需類別屬性、requests 需模組層導入。
5. QML context property 非同步編譯競態（Bridge 偶發 null）→ 改用 qmlRegisterSingletonInstance 註冊，5 連測 0 錯誤。
6. ModePill/Slider 信號與屬性變更信號重名 → 更名。
7. historyModel 未暴露為 Qt Property → QML 看不到模型。
8. 彈窗卡片無高度 → 內容溢出但答案區寬度 0 → 顯式高度。
9. 離屏平台無內建字體 → 手動載入系統字體（msyh/segoe）。
10. engine 局部變數被 GC 銷毀視窗 → 綁定到 app 保活。
11. 截圖改用 QScreen.grabWindow（QWindow 型別無 grabWindow）。

## 六、已知限制

- 桌面雙模型並行（cn+en）對非該語言語音會輸出雜訊；偵測層以「是否問題＋熱詞」過濾，實測不影響彈窗正確性。
- 點名偵測需先在設定填寫名字（中/英/粵）。
- AI 接駁未配置時為離線模式（知識庫＋答題框架），答案以課本為準。
- 安卓打包需在 Linux + Android SDK 完成（指南見 android/README_OPPO_GUIDE.md）；本機無 Android SDK，桌面端全流程已驗證。
